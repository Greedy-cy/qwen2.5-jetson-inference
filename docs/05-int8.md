# 05 INT8 Weight-only 量化

Linear 权重按 `[out, in]` 排列，沿 in/K 维每 64 个元素使用一个对称 scale：

```text
scale = max(abs(group)) / 127
q = clamp(round(w / scale), -127, 127)
```

Embedding、Norm、bias 和 tied LM head 保留 FP32。这解释了文件不是缩小到 FP32 的
四分之一：词表 embedding 约占模型参数的 27%，仍需 FP32 存储。CUDA W8A32 kernel
在读取 int8 时按 group 乘 scale，与 FP32 activation 相乘并以 FP32 累加，不生成完整
反量化权重。

导出后的 `export_report.json` 记录每个 tensor 的最大/平均重构误差。优化必须同时查看
误差、tok/s、文件大小和峰值内存，不能只报告吞吐。
